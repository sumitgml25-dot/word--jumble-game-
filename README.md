# Word Jumble Game

A Python-based Word Jumble Game where players unscramble randomly selected words within limited attempts, use hints, earn scores, and play multiple rounds.

## Problem Statement

Develop a Python-based word puzzle game that presents users with scrambled words. The player must guess the correct word within a limited number of attempts. The game provides hints, maintains scores, and allows multiple rounds of gameplay.

## Objectives

- Develop an interactive word puzzle game using Python.
- Implement random word selection and word scrambling.
- Provide limited attempts and hints.
- Maintain and display the player's score.
- Allow multiple rounds of gameplay.
- Apply Python programming concepts practically.

## Technologies Used

- Python

## Planned Features

- Random word selection
- Word scrambling
- Limited attempts
- Hint system
- Score system
- Multiple rounds
- Input validation
